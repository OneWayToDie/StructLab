# StructLab

Учебный проект на WPF (.NET Framework 4.8) с набором лабораторных работ и встроенным модулем чтения книг.

Модуль чтения умеет искать произведения в Викитеке, открывать локальные EPUB-файлы,
показывать оглавление, сохранять прогресс, ставить закладки и искать по тексту всей книги.

> Проект собирается под **x64**: C++-библиотека `LabLogic.dll` существует только в 64-битной версии.

## Возможности

- **Лабораторные работы** — задания по структурам данных и алгоритмам (C++ + C#/WPF).
- **Поиск в Викитеке** — поиск произведений, загрузка глав, кэширование.
- **EPUB** — открытие локальных `.epub`, разбор оглавления и текста, история книг.
- **Прогресс чтения** — позиция в книге восстанавливается при следующем открытии.
- **Закладки** — сохранение позиции в главе, переход и удаление.
- **Поиск по книге** — по всем главам сразу, с переходом к найденному фрагменту.
- **Оформление** — размер и шрифт текста, светлая/сепия/тёмная темы.

## Требования

- Windows 10/11
- Visual Studio 2022 с компонентами:
  - «Разработка классических приложений .NET»
  - «Разработка классических приложений на C++»

## Сборка и запуск

1. Откройте `StructLab.sln` в Visual Studio 2022.
2. Выберите конфигурацию **Debug** и платформу **x64**.
3. Назначьте проект `StructLab` стартовым и нажмите **F5**.

Сборка из командной строки:

```powershell
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" `
    "StructLab.sln" /p:Configuration=Debug /p:Platform="x64"
```

> При сборке `LabLogic.dll` копируется в `StructLab\bin\Debug`, поэтому запускать приложение
> нужно из этой папки (или через Visual Studio).

### Модуль чтения

| Слой | Назначение |
|------|------------|
| `IBookSourceProvider` | Источник книг: поиск и загрузка содержимого |
| `WikisourceProvider` | Провайдер Викитеки (MediaWiki API) |
| `EpubProvider` | Разбор локальных EPUB через `VersOne.Epub` + кэш |
| `ReadingService` | Поиск/загрузка с кэшированием |
| `FileBookCache` | Файловый кэш книг |
| `EpubLibraryStore` | История открытых EPUB |
| `ReadingProgressStore` | Позиция чтения по книге |
| `BookmarkStore` | Закладки по книге |
| `ReaderViewModel` | Вся логика окна читалки |
| `ReaderWindow` | WPF-окно: оглавление, поиск, закладки, настройки |

Зависимости собираются в `App.xaml.cs` через `Microsoft.Extensions.DependencyInjection`.
`ReaderViewModel` получает сервисы через конструктор.

### Где хранятся данные

Всё лежит в `%LocalAppData%\StructLab`:

| Файл | Содержимое |
|------|------------|
| `reading-settings.json` | Шрифт, размер, тема |
| `reading-progress.json` | Позиции чтения (одна запись на книгу) |
| `bookmarks.json` | Закладки всех книг |
| `epub-library.json` | История открытых EPUB |
| `cache\epub\{sha1}.json` | Разобранные EPUB |
| `cache\wikisource\` | Кэш Викитеки |
| `logs\reading.log` | Диагностический лог читалки |
